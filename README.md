# صنعت متال — وب‌سایت فروش لوله، فلنج و شیرآلات صنعتی

ASP.NET Core 10 (MVC) + SQL Server + EF Core

## امکانات

**سایت عمومی (فارسی / انگلیسی، تم تیره و روشن، کاملاً واکنش‌گرا)**
- اسلایدر صفحه اصلی از عکس محصولاتی که در پنل «نمایش در اسلایدر» دارند
- دسته‌بندی‌ها، محصولات ویژه، «چرا ما»، اسلایدر لوگوی مشتریان (پالایشگاه‌ها و شرکت‌ها)
- لیست محصولات با جستجو، فیلتر دسته و متریال، مرتب‌سازی و صفحه‌بندی
- صفحه محصول: گالری عکس، جدول سایزها (سایز، کلاس، اسکجول) با قیمت، تخفیف یا «تماس بگیرید»، گواهی‌ها و دیتاشیت‌ها با نسخه و تاریخ اعتبار
- صفحه همه گواهی‌ها و دیتاشیت‌ها
- سبد خرید (کشویی و صفحه کامل) و ثبت سفارش فقط با شماره موبایل
- فرم ارسال درخواست در صفحه اصلی: هم ایمیل می‌شود و هم در جدول `ContactMessages` ذخیره می‌شود؛ اگر سرور ایمیل قطع باشد، پیام در پنل قابل خواندن و ارسال مجدد است

**پنل ادمین (فارسی، سایدبار راست، تم تیره و روشن)**
- داشبورد با نمودار فروش ۶ ماه، نقدی/چکی، سفارش‌ها، پیام‌ها و هشدار انقضای گواهی‌ها
- محصولات، سایزها، عکس‌ها (اصلی / اسلایدر)، گواهی‌ها و دیتاشیت‌ها (نسخه قبلی آرشیو می‌شود)
- دسته‌بندی‌ها و متریال‌ها
- قیمت‌گذاری: قیمت خرید، فروش، نقدی، چکی، مدت چک، درصد تخفیف، تأمین‌کننده، با تاریخچه کامل؛ تغییر گروهی درصدی
- سفارش‌های سایت و تبدیل سفارش به پیش‌فاکتور / فاکتور
- فاکتور: جستجوی کالا، تخفیف ردیفی و کلی، مالیات، حمل، پرداخت نقد / چک / ترکیبی، PDF، چاپ، سطل بازیافت
- گزارش‌ها با خروجی Excel و PDF: فروش، فروش کالا (با سود)، فروش هر خریدار، لیست قیمت، تاریخچه قیمت، سفارش‌ها
- خریداران، مشتریان ما (لوگو)، پیام‌ها، تنظیمات سایت و SMTP، کاربران، ماتریس دسترسی، گزارش فعالیت کاربران

## نقش‌ها و دسترسی پیش‌فرض

| بخش | سوپر ادمین | ادمین | مسئول فروش | حسابدار / منشی |
|---|---|---|---|---|
| محصولات | ✔ | ✔ | ✔ | فقط مشاهده |
| قیمت‌گذاری و قیمت خرید | ✔ | ✔ | ✔ | ✘ |
| فاکتور: ثبت / حذف | ✔ | ✔ | ✔ | ✔ |
| فاکتور: ویرایش کامل | ✔ | ✔ | ✔ | ✘ |
| گزارش‌ها | ✔ | ✔ | ✔ | ✘ |

سوپر ادمین از «سطوح دسترسی» می‌تواند هر کدام را روشن یا خاموش کند.
اگر منشی در فاکتور کالای کاتالوگ اضافه کند، قیمت آن از جدول قیمت پر می‌شود و قابل تغییر نیست.

## اجرا

پیش‌نیاز: .NET SDK 10 و SQL Server (2019 به بعد یا Express).

1. رشته اتصال را در `src/SanaatMetal/appsettings.json` (یا متغیر محیطی `ConnectionStrings__DefaultConnection`) تنظیم کنید.
2. برای ساخت اولین سوپر ادمین این مقادیر را تنظیم کنید (بهتر است با user-secrets یا متغیر محیطی، نه داخل فایل):
   ```
   Seed__AdminEmail=you@company.com
   Seed__AdminPassword=یک رمز قوی (حداقل ۱۰ کاراکتر با حرف بزرگ، کوچک، عدد و نماد)
   ```
3. اجرا:
   ```
   cd src/SanaatMetal
   dotnet run
   ```
   جدول‌ها با Migration به‌صورت خودکار ساخته می‌شوند. پنل: `/admin` (نام کاربری پیش‌فرض: `superadmin`).
4. در محیط Development اطلاعات نمونه (محصول، قیمت، لوگو) و کاربر `superadmin` با رمز `Admin@123456` ساخته می‌شود. در Production حتماً `Seed:DemoData` را false بگذارید و رمز را عوض کنید.

اجرای سریع بدون SQL Server (فقط برای دیدن سایت): `Database__Provider=Sqlite dotnet run`

Migration جدید پس از تغییر مدل‌ها:
```
dotnet tool restore
dotnet ef migrations add NameOfChange -p src/SanaatMetal -o Data/Migrations
```

## انتشار روی سرور (IIS یا لینوکس)
راهنمای کامل قدم‌به‌قدم: [DEPLOY.md](DEPLOY.md)
- `dotnet publish src/SanaatMetal -c Release -o publish`
- پوشه `wwwroot/uploads` باید قابل نوشتن باشد و در بکاپ قرار بگیرد.
- HTTPS را فعال کنید؛ در Production هدر HSTS و ریدایرکت به HTTPS فعال است.
- کلیدهای Data Protection را در مسیر ثابت نگه دارید تا رمز SMTP ذخیره‌شده و لاگین‌ها پس از ری‌استارت معتبر بمانند.

## امنیت
- ASP.NET Core Identity با رمز قوی، قفل حساب بعد از ۵ تلاش ناموفق، کوکی HttpOnly و SameSite=Strict
- توکن ضد CSRF روی همه فرم‌ها، محدودیت تعداد درخواست برای ورود، فرم تماس و ثبت سفارش، فیلد مخفی ضد ربات
- هدرهای امنیتی (CSP بدون اسکریپت درون‌خطی، X-Frame-Options، nosniff، Referrer-Policy، Permissions-Policy)
- بررسی پسوند، حجم و امضای واقعی فایل‌های آپلودی و نام‌گذاری تصادفی؛ SVG و فایل اجرایی پذیرفته نمی‌شود
- قیمت‌ها و جمع فاکتور همیشه در سرور محاسبه می‌شود؛ حذف فاکتور نرم است و قابل بازگردانی
- رمز SMTP با Data Protection رمزنگاری می‌شود؛ همه عملیات مهم در گزارش فعالیت ثبت می‌شود

## لوگو
- فایل‌های لوگو در `wwwroot/img/brand` هستند: نشان (`logo-mark.svg`)، لوگوی افقی فارسی و انگلیسی، نسخه سفید برای زمینه تیره و لوگوی عمودی. متن‌ها به مسیر تبدیل شده‌اند و به فونت وابسته نیستند.
- favicon، آیکون iPhone (`apple-touch-icon.png`) و تصویر اشتراک‌گذاری (`og-image.png`) هم آماده‌اند. لوگو در هدر فاکتور و گزارش‌های PDF هم چاپ می‌شود.
- اگر لوگوی دیگری در «تنظیمات» آپلود شود، در هدر سایت جایگزین می‌شود.

## فونت‌ها
- متن: Vazirmatn، تیترها: Lalezar (هر دو با لایسنس آزاد OFL، داخل پروژه).
- فونت «تیتر» (B Titr) لایسنس آزاد ندارد. اگر نسخه مجاز آن را دارید، فایل `titr.woff2` را در `wwwroot/fonts` بگذارید تا خودکار جایگزین لاله‌زار شود.
